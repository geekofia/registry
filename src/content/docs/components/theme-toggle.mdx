## Usage

```tsx
import { ThemeToggle } from "@/components/theme-toggle";

<ThemeToggle labels={{ toggle: "Thème", light: "Clair", dark: "Sombre", system: "Système" }} />;
```

Inside a [theme provider](/registry/components/theme-provider/). `labels` translates it;
`className` is added to the button.
