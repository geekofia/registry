## Usage

```tsx
import { Switch } from "@/components/switch";

<label className="flex items-center gap-3">
  <Switch checked={on} onCheckedChange={setOn} />
  Notifications
</label>;
```

It takes Base UI's `Switch.Root` props (`checked`, `defaultChecked`, `onCheckedChange`,
`disabled`, `name`, …). Name it with a wrapping `<label>`, or `id` and `<label htmlFor>`.
