---
title: Theme init
description: Sets the theme's class before the app starts, so a dark theme doesn't flash light.
---

import Install from "../../../components/Install.astro";

React runs after the first paint, so without this a dark theme flashes light on every load. Load it
from `<head>`, before your app's script:

```html title="index.html"
<head>
  <script src="/theme-init.js"></script>
</head>
```

It's a file rather than inline, so a Content-Security-Policy of `script-src 'self'` allows it. Keep
its `STORAGE_KEY` and `DEFAULT_THEME` the same as the [theme provider](/registry/components/theme-provider/)'s
(`theme` and `system` by default).
