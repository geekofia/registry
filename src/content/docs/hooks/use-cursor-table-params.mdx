Cursors only go next or previous, so there's no page number, and a new search, sort or page size
goes back to the first page, as an old cursor wouldn't line up with the new results. Pairs with the
[data table](/registry/components/data-table/).

```tsx
import { useSearchParams } from "react-router";
import { useCursorTableParams } from "@/hooks/use-cursor-table-params";

const params = useCursorTableParams(useSearchParams(), { defaultPerPage: 20 });
// params.search, sortDirection, perPage, after, before
// params.setSearch, setSortDirection, setPerPage, goToNextPage, goToPreviousPage
```

Any router works: pass `[searchParams, (update) => …]`, where `update` takes the current params and
returns the next.
